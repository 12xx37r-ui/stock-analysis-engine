STOCK ANALYSIS ENGINE V6.8.0 — ASSET CYCLE ANCHOR PATCH

목적
- 현대건설 한 종목 예외처리가 아니라, 자산집약·사이클 기업에서 일시적으로 낮아진 이익가치(PER 계열)가
  순자산·잔여이익·Graham·FCF 등 독립 가치앵커와 과도하게 괴리되는 경우를 일반 규칙으로 교차검증합니다.
- 현재가/시가총액으로 적정가를 끌어올리지 않습니다.
- 기존 정상 기업의 적정가는 가능한 그대로 유지합니다.
- 새 API/네트워크 호출을 추가하지 않습니다.

업로드 파일 (3개)
1) analyzers/valuation.py              -> 기존 파일 덮어쓰기
2) predictor.py                        -> 기존 파일 덮어쓰기
3) validate_asset_cycle_anchor.py      -> 새 검증파일 추가 (선택이지만 권장)

- collectors/*
- .github/workflows/*

- 캐시 구조
- GAS/HTML

핵심 안전장치
- 대상은 회사명/종목코드가 아니라 산업 프로필 + 재무조건으로 판정합니다.
- TTM EPS > 0, BPS > 0, 현재가치모형 3개 이상, 독립 자산앵커 2개 이상을 요구합니다.
- 자산앵커 중앙값이 현재 이익가치의 2.40배 이상일 때만 후보입니다.
- 현재 모형분산이 6배를 넘으면 자동 차단합니다.
- 새 보정값이 기존 V4 기본적정가보다 최소 15% 높을 때만 승격합니다.
- 손실/자료부족 기업에 자산가치 하나만으로 적정가를 강제하지 않습니다.
- 현재가를 1만원/100만원으로 바꿔도 같은 재무입력이면 적정가는 동일하도록 회귀검증했습니다.

현대건설 로컬 회귀검증 (업로드 ZIP에 포함된 기존 저장 스냅샷 기준)
- 기존 기본적정가: 약 16,774원
- 수정 후 모델값: 약 53,267원
- 이는 '실제 적정가가 반드시 53,267원'이라는 뜻이 아니라, 같은 저장 재무입력에 새 교차검증 규칙을 적용한 모델 산출값입니다.
- 현재가 110,600원은 가치 계산식에 사용하지 않았습니다.

중요 — 기존 게시 JSON 갱신
- 이 패치는 엔진 코드를 수정합니다. 이미 GitHub에 게시된 data/latest/stocks/000720.json 자체는 파일 업로드만으로 자동 재작성되지 않습니다.
- 현대건설 화면값을 즉시 새 계산으로 바꾸려면 기존 on-demand-stock-analysis Action을 종목코드 000720으로 1회 실행하십시오.
- 새 workflow/Action을 만들 필요는 없습니다.
- 이후 새로 생성/갱신되는 종목은 수정된 계산을 자동 사용합니다.

산업 문구 오류도 함께 수정
- 비반도체 기업에도 '반도체 산업 대표자산'이라고 표시되던 고정 문구를 실제 산업명으로 변경했습니다.
- 예: 현대건설 -> '건설·인프라 대표자산 합성', '건설·인프라 대표자산 1년 추세'

버전 호환성
- 기존 소비 프로그램과의 연결을 깨지 않기 위해 가치평가 계약 4.0 / Engine 6.8.0 / 기존 model revision 문자열은 유지합니다.
- 대신 출력에 자산사이클보정버전/적용여부/앵커 진단 필드를 additive 방식으로 추가합니다.
